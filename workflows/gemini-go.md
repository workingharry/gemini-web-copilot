# Workflow: /go with Antigravity Execution & Debug

本工作流指導 Antigravity 在 `/plan` 獲得用戶審核批准後，如何全自動接手執行實作、修復工程盲點、撰寫單元測試並完成落地除錯。

---

## 觸發條件
當用戶在對話中輸入 `/go`，或給予「批准計畫 / 開始執行」反饋時觸發。

---

## 執行步驟

### 步驟 1：計畫任務解構
1. 讀取審核通過的規劃文檔（如 `docs/gemini_plan.md` 或 Artifact 中的計畫）。
2. 將實作項目拆解為具體、依賴清晰的單元步驟。

### 步驟 2：程式碼落地與工程修復
1. 在專案中建立或修改相應檔案。
2. **關鍵工程防護檢查**（Antigravity 專業把關）：
   - 檢查非同步競爭條件與超時掛起漏洞（視需求加入 `Promise.race` 超時保護）。
   - 檢查是否支援取消訊號（如 `AbortSignal`）。
   - 檢查執行環境相容性（如 TypeScript 構造器屬性宣告）。

### 步驟 3：撰寫單元測試與自動驗證
1. 針對新功能撰寫涵蓋正常、異常、邊界條件的單元測試（如 `tests/*.test.ts`）。
2. 在終端執行測試指令（如 `node --test` 或 `npm test`）。
3. 執行專案構建指令（如 `npm run build`）。

### 步驟 4：交付驗證總結
1. 產出 `walkthrough.md` 總結實作成果、測試通過率與修復細節。
2. 通知用戶驗證完成。
